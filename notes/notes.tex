	\section{Overall information}
	The overall problem we want to address in this project is to understand how the predictions of a Gaussian process (GP) depend on the choice of kernel and their ability of uncertainty estimation.
	Thus, we need a simple, but physical relevant toy model. These criterias are fulfilled for the $T_3$ data set of NNPDF. It consists of a convolution of two functions, the Wilson coefficient $C_3$ and the PDF $T_3$.
	Additionally, the $T_3$ dataset was used in the first NNPDF paper proving that a NN can be used to parameterize a single PDF and was also used in Ref.~\cite{DelDebbio:2024qfh} as first model showing that GP's can be used for single PDF fits.

	We want to improve the fit quality and uncertainty estimation compared to previous work and perform some benchmarking not only against previous NNPDF fitting techniques but also against Bayesian Neural Networks (BNNs) in terms of accuracy and uncertainty estimation.

	\section{Gaussian Process}
	A GP is defined as nonparametric, supervised learning method for regression and probabilistic classification tasks. Its prediction is a probabilistic interpolation of observations based on the input data. For a typical regression task, the GP combines a specific, set prior with a likelihood based on training samples, thus it provides a probabilistic approach for predictions, being capable of estimating a mean and standard deviation.
	Since the toy model is only a first step and we want to extend the study to physics data and its application and implementation in COLIBRI, we need to understand how this mean and standard deviation is obtained and what class of uncertainty does it provide.
	Starting from the prior distribution of the GP, where the prior mean is specified in the GP regression function. The mean of the prior is either constant at zero or can be set to the mean value of the training data. The corresponding covariance of the prior is specified by the kernel choice. The hyperparameters of the choosen kernel are optimized during the training process of the GP by a maximum log-marginal likelihood approach, based on the used optimizer. The initialisation parameters for the optimizer are sampled from the allowed range of hyperparameters in the kernel. 
	
	The GP now finds a distribution over all possible functions $f(x)$ consistent with the observed data, by starting from the prior and via optimizer updates it moves closer to the underlying posterior distribution and uses the covariance matrix of the prior to ensure smoothness in the resulting function. Thus, the covariance matrix and the mean of all possible functions defines a GP.
	Based on the input data $x_1, ..., x_n$, the GP assumes a probability distribution of $p(f(x_1),...,f(x_n))$ is jointly Gaussian in combination with a mean $\mu(x)$ and a covariance $\Sigma_{x}$, where $\Sigma(x)$ is constructed as $\Sigma_{ij}=\text{kernel}(x_i,x_j)$.
	The key idea is that if $x_i$ and $x_j$ are deemed by the kernel to be similar, then we expect the output of the function, $f(x_i)$ and $f(x_j)$ to be similar too.
	Thus, the essence of a GP is a multivariate Gaussian which shape is determined by the covariance matrix using conditional probabilities to determine the posterior from the underlying prior, written as
	%
	\begin{align}
		\begin{pmatrix}%
		x_1 \\ x_2
		\end{pmatrix}
		= \mathcal{N} \left(
		\begin{pmatrix}
		\mu_1 \\ \mu_2
		\end{pmatrix}
		,
		\begin{pmatrix}
		\sigma_{11} & \sigma_{12}\\ \sigma_{21} & \sigma_{22}
		\end{pmatrix}
		\right) \;,
	\end{align}
	%
	with $\sigma$ the variance and its correlation of the multivariate Gaussian.
	In terms of functions $f(x)$, the posterior can be described as joint probability of outcome values of possible funtions, where $f$ are the observed functions of points $x$ and the functions we would like to estimated based on points $x_\star$ with $f(x_\star)=f_\star$. 
	Similar to the equation above, we can write
	%
	\begin{align}
		\begin{pmatrix}%
		f \\ f_\star
		\end{pmatrix}
		= \mathcal{N} \left(
		\begin{pmatrix}
		\mu \\ \mu_\star
		\end{pmatrix}
		,
		\begin{pmatrix}
		K & K_\star\\ K_\star^\top & K_{\star\star}
		\end{pmatrix}
		\right) \;,
	\end{align}
	%
	with $K$ the matrix we get from applying the kernel function $k$ on observed $x$, $K_\star$ is the kernel function applied on train and test data, to relate their similarities and $K_{\star\star}$ relates the test values to each other.
	So we try to get $p(f_\star | x_\star, x, f)$ by using the relation between $p(f, f_\star)$ and $p(f_\star|f)$ with $f_\star \approx \mathcal{N}(\mu_\star, \Sigma_\star)$ and that $f$ and $f_\star$ are together jointly Gaussian.

    \section{Toy model}
    We started with a first, simple toy example to investigate the behaviour and function of Gaussian processes (GPs) in a simple regression problem using a continuous function
    %
    \begin{align}
    	f(x) = \sin(2\pi \cdot x) + 0.5 \cdot x \; .
    \end{align} 
    %
	As training data set, we generate $20$ random points, where some artificial noise is added on top of the true values as
	%
	\begin{align}
		D_\text{train} = f(x_i) + 0.1 \cdot \mathcal{N}(0, 1) \; ,
	\end{align}
	%
	and as test dataset we use $100$ randomly choosen points. 
	With this set-up we train a GP to estimate the function $f$ defined above and test different kernel and approaches on their abilities of recovering the true distribution. The uncertainty we get from such a GP is an epistemic or statistical uncertainty arising from model simplifications and lack of data.

	\subsection{On uncertainties} %cite VEraiphy report?
	In physics analyses we distinguish betweeen two different kinds of uncertainties, systematic and statistical ones.
	Statsistical uncertainties hereby originate from a finite data set size and stochastic fluctuations in the results when the experiment gets repeated. Thus statistical uncertainties decrease with more data.
	Systematic uncertainteis on the other hand arise from an imperfect knowledge of measurement conditions, detector effects or flaws in the underlying theoretical model. Thus, they do not vanish with more data.

	In the machine learning or statistics convention, uncertainteis are separated into aleatoric and epistemic ones.
	Aleatoric uncertainties are data uncertainites from some inherent randomness and fluctuations within the data generation process and are thus irreducible. 
	Epistemic uncertainties are model uncertainties, describing a lack of knowledge about the model or its parameters. These can be reduced by taking more data into account, improved modeling or theoretical input. With this we can separate the epistemic uncertainties into three subcategories:
	%
	\begin{itemize}
		\item training variability from imperfect training, as cause could be multiple local minima or an imperfect optimization of hyperparameters
		\item data variability, because we only have a finite amount of data available
		\item model bias, when the truth distribution cannot be matched, due to wrong underlying hypothesis, or the truth is outside the scope of the hypothesis.
	\end{itemize}
	%
	From these three subcategories, training and data variability can be categorized as statistical uncertaintiy from a physics persepctive and the model bias as systematic uncertainty.
	Both approaches, systematic/statistical and aleatoric/epistemic, describe different features and thus cannot be used interchangable but complementary. A summary of both approaches and how they relate to each other is shown in Tab.~\ref{tab:unc}.
	%
	\begin{table}[htpb]
		\centering
		\begin{tabularx}{\linewidth}{lXX}
			\toprule
			& \textbf{aleatoric (data uncertainty)} & \textbf{epistemic (model uncertainty)}\\
			\midrule
			\textbf{systematic} &
			Irreducible, stocastic effects in calibration or background effects &
			Imperfect model assumptions, limited theoretical knowledge \\
			\midrule
			\textbf{statistical} &
			Data fluctuations due to finite sampling & 
			Model uncertainty from limited data (overfitting, poorly constrained parameters)\\
			\bottomrule
		\end{tabularx}
		\caption{Uncertainty classification}
		\label{tab:unc}
	\end{table}

	\subsection{More notes on different kernels}

	\subsubsection*{Constant kernel} %Scikit documentation page
	A constant kernel $k_C$ is defined as
	\begin{align}
		k_C (x, x') = \mathrm{const.}
	\end{align}
	and implemented as ConstantKernel=(1.0, (1e-3, 1e3)), where the initial constant value is set to $1.0$, but is allowed to vary between $0.001$ and $1000$ during the optimization process.
 
	\subsubsection*{RBF kernel} %scikit documentation page
	Also known as squared exponential or Gaussian kernel:
	\begin{align}
		k(x, x') = \exp(- \frac{(x-x')^2}{2l^2}) \; ,
	\end{align}
	where $l$ denotes the kernel length-scale. This length-scale controls the smoothness of the kernel.
	Thus, the RBF kernel provides a good estimate for a variety of smooth functions, ideal for cases where we have a limited prior knowledge.
	The RBF kernel is implemented as RBF(1.0, (1e-2, 1e2)), where the kernel length $l=1.0$ and can vary between $0.01$ and $100$ during optimization.

	\subsubsection*{NTK} %NTK paper 1902.06720v4
	Neural Tangent kernels (NTKs) also known as infinite-width kernel:
	\begin{align}
		k_{\text{NTK}}(x, x'; \theta) = \nabla_{\theta} f(x; \theta) \cdot \nabla_{\theta} f(x' ; \theta) \; ,
	\end{align}
	with $f_{\theta}(x)$ denoting the output of a neural network parameterized by $\theta$.
	It was first introduced to describe the evolution of a deep NN during gradient descent. Opposite to other kernels, NTKs are specifically derived for their use with neural networks.
	Thus with a NN parameter $\theta$ change during training, the kernel evolves as well, letting us capture the training dynamics.
	In the infinite width limit of the NN the NTK has some nice properties:
	\begin{itemize}
		\item NTK is deterministic (independent of random parameter intialization)
		\item NTK constant during training
		\item Each parameter itself changes negligibly during training, but collectively the provide a finite change in variables
		\item During training network is linearized: Use first order Taylor expansion for parameter dependence 
			  $f(x;\theta_0 + \Delta \theta) = f(x; \theta_0) + \Delta \theta \cdot \nabla_\theta f(x; \theta_0)$, $\theta_0$ initial parameters
		\item Training dynamics are equivalent to a kernel gradient descent using the NTK as kernetl. If the loss is an MSE loss, the final distribution $f(x; \theta)$ remains a GP but with new mean and variance.   
	\end{itemize}

	\subsubsection*{NNGP kernel} %based on 1902.06720v4
	The neural network Gaussian process (NNGP) uses a Gaussian process as posterior estimate and thus also models a deep, infinitely wide NN. It uses a Bayesian model to average over randomly distributed, infinite-wide networks.
	The uncertainty estimate of this NNGP originates from the Bayesian approach of the posterior estimation, where we get a posterior variance from the introduced covariance matrix. This uncertainty is thus a so-called model uncertainty, or epistemic uncertainty.
	The kernel is computed as 
	%
	\begin{align}
		K^{i,j} (x, x') = \lim_{\min{(n_1,...,n_L)} \rightarrow \infty} \mathbb{E} \left[ f_0^i (x) \cdot f_0^j(x') \right] \; ,
	\end{align}
	%
	where $K^{i,j}$ denotes the covariance between the i-th output of $x$ and the j-th output of $x'$, with $x$ and $x'$ elements of the training data set. $f_t^i (x)$ describes the i-th output of the NN with input $x$ at a time $t$ and thus $f_0^i(x)$ is the i-th output at initialization of the input $x$, sampeled from a Gaussian distribution as $f_0(\mathcal{X}) \sim \mathcal{N}(0, K(\mathcal{X}, \mathcal{X}))$ and $\mathcal{X} = \{ x: (x,y) \in D\}$ with $x$ inputs and $y$ labels. Accordingly one can define $\mathcal{Y} = \{ y: (x,y) \in D\}$. The $n_l$ denote the width of the $L$ hiddenlayer with $l=1,...,L$. Thus $k_\text{NNGP} (x, x')$ is defined as matrix with entries $K^{i,j} (x, x')$ for all input features.

	\subsubsection*{Gibbs kernel} %T3 deldebbio paper
	The study in Ref~\cite{Candido:2024hjt} for the $T_3$ dataset approximated by a GP used a Gibbs kernel in their model.
	This Gibbs kernel is similar to the RBF kernel but as a more advanced function. It can be expressed in the following way
	%
	\begin{align}
		k_\mathrm{Gibbs} (x, x') = \sigma^2 \sqrt{\frac{2l(x) 2l(x')}{l^2(x)+l^2(x')}} \exp \left[ - \frac{(x-x')^2}{l^2(x)+l^2(x')} \right] \; ,
	\end{align}
	with 
	\begin{align}
		l(x) = l_0 \times (x+\delta) \; .
	\end{align}
	%
	The GP hyperparameters are denoted as $l_0$, the kernel length and $\sigma^2$, some constant prefactor to adjust the width.
	$\delta$ is implemented as small fixed number to regularize $k_\mathrm{Gibbs}$ when $x, x' \rightarrow 0$. For $x\rightarrow 0$, the correlation length in this kernel decreases linearly in $x$ to reflect limited knowledge in the small-$x$ regieme of PDF fits.

	\subsubsection*{Matern kernel} %Scikit lern webpage
	The Matern kernel is a generalization of the previously introduced RBF kernel with an additional parameter $\nu$ to control the smoothness of the function. For $\nu \rightarrow \infty$ the Matern kernel is equivalent to the RBF kernel, while for $\nu = 0.5$ it is the absolute exponential kernel. Other useful values are $\nu =1.5$ symbolising a once differential function and $\nu = 2.5$ for a twice differenttiable function.
	The kernel is written down as
	%
	\begin{align}
		k_\mathrm{Matern} (x, x') = \frac{1}{\Gamma(\nu) 2^{\nu-1}} \left( \frac{\sqrt{2\nu}}{l} d(x, x') \right)^\nu K_\nu \left( \frac{\sqrt{2\nu}}{l} d(x, x') \right) \; ,
	\end{align}
	%
	with $d(x, x')$ the Euclidean distance, $K_\nu$ a modified Bessel function and $\Gamma$ the Gamma function.
